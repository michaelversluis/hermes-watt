# Hermes Watt 0.1.0

Plan: HERMES-WATT-1, version 1. Michael approved completing the plugin in this conversation on 2026-11-08.

An independent open-source submission to the Hermes Plugin Hackathon, with no WVE customer or production integration.

Acceptance:
- Load through public Hermes APIs and pass catalog validation on a recorded Hermes revision.
- A local metadata-only receipt per turn; request/error/auxiliary accounting without duplicate event counting.
- Apple CPU + GPU telemetry is labelled estimated, system-wide, incomplete scope. Remote inference is unknown.
- Missing or failed measurement stays unknown, never zero. Concurrent windows are not summed.
- A Desktop overview and /watt command with no external reporting.
- Repeatable local model comparison, identical inputs and correctness checks, raw evidence, no predetermined savings claim.
- README, method, privacy/dependency disclosures, CI, public repository/PR and catalog submission material.

Deferred: provider-specific cloud estimates, CO2 conversion, automatic model routing, arbitrary command execution and production installation.

Owner/builder: Codex, explicitly authorized for this independent project. Review: tests, catalog validator and source review; no claim of independent human approval.
